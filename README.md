# Default Community Health Files

This repository contains the [default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) that apply automatically to all repositories within Volcanic organization.

These files help ensure consistency in how we collaborate, review, and maintain our projects.

## Purpose

GitHub automatically applies these default files to any repository that does not include its own equivalents.  
This helps standardize community and contribution practices across all projects.
